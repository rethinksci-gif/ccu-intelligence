# Manual review workspace

Files in this folder are ignored by Git, except this guide and the illustrative assumptions example. Store permitted source text and working review bundles here. Review original evidence and reproduction rights before moving selected records into `data/curated/`.

Use `python -m ccu_intelligence.cli snapshot data/manual/review.json` to save the working bundle. Its candidates are not publishable by default. See `docs/editorial.md` for claim review, event application and publication instructions.

Copy `assumptions.example.json` to `assumptions.json` to try a reproducible, explicitly illustrative calculation. No price in the example is a market observation.
